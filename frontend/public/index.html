About Privacy Shield

Project Overview

Privacy Shield is a university research project for Security and Privacy for Machine Learning (216H17C701). It demonstrates how multiple privacy-preserving techniques can be combined to protect sensitive information while maintaining fraud detection performance.

Privacy Mechanisms

  • Input Modification: Generalizes sensitive attributes (e.g., age to age groups)
  • Local Differential Privacy: Randomizes individual records before central processing
  • Compressive Privacy: Reduces feature dimensionality via PCA
  • Differential Privacy-SGD: Formal privacy guarantee through gradient noise during training

Threat Model

Attacker: Has black-box query access to the model but doesn't know the training data or model weights.

Attack: Uses model predictions to infer sensitive attributes about training records.

Defense: Combines input modification, LDP, compression, and DP-SGD to make attribute inference difficult.

Dataset

Bank Account Fraud (BAF) dataset with 1,000,000 transactions. Highly imbalanced (98.9% legitimate, 1.1% fraud). Demo uses 10K samples for tractability.

Important Disclaimers

  • This is a research/educational demonstration, not production-ready code
  • Model Inversion Attacks don't guarantee recovery of real private information
  • Formal DP guarantees are theoretical and depend on assumptions
  • Real deployment requires additional security controls

Sources

  • Dataset: Feedzai Bank Account Fraud
  • Privacy: Differential Privacy, Local DP, and Compressive Privacy literature
  • Attacks: Model Inversion Attack papers (Fredrikson et al.)
