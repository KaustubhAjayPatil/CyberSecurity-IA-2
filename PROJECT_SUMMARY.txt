🔧 CONFIGURATION OPTIONS
═══════════════════════════════════════════════════════════════════════════════

Edit .env file to customize:

Privacy Strength
─────────────────
DP_EPSILON=1.0           Default privacy budget (lower = stronger)
LDP_EPSILON=1.0          Local DP budget
COMPRESSION_RATIO=0.8    PCA compression (0.6 = more aggressive)

Model Training
────────────────
BASELINE_EPOCHS=20       Baseline training time
DP_EPOCHS=20            DP-SGD training time
BASELINE_LEARNING_RATE=0.001
DP_LEARNING_RATE=0.001

Dataset
──────────
DATASET_SAMPLE_SIZE=10000   Sample size (fewer = faster)
DATASET_RANDOM_SEED=42      Reproducibility

Deployment
───────────
BACKEND_PORT=8000        API server port
BACKEND_HOST=0.0.0.0     Listen address
